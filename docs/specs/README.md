# Specs

What Keellay does now, one file per capability. The format is [method/formats/spec.md](../../method/formats/spec.md).

| Capability | Covers |
|---|---|
| [cli](cli.md) | The `keellay` command: version, output contract, `info`, commands not built yet |
| [paths](paths.md) | `keellay paths`: the project's root, level and sections, from defaults and `.keellay/config.toml` |
| [check](check.md) | `keellay check`: front matter, numbers, indexes and links, on the working tree or the staged files |
